# Put this project on GitHub

1. Create a new **public** repository, for example `pokemon-team-overlay`.
2. Leave automatic README, license, and gitignore generation unchecked: this
   package supplies them.
3. Extract the package, then upload its contents into the repository root using
   **uploading an existing file** (or **Add file → Upload files**).
4. Include `.gitignore` as well as all visible files. Do not upload the ZIP itself,
   installed dependencies, or any `pokemon-team-data.json` save file.
5. Commit the upload. The README will become the repository's front page.
6. Share the repository link. Users can select **Code → Download ZIP**.

For an optional release, create a tag such as `v1.0.0`, describe the release,
and attach `pokemon_team.py` for a one-file download. This has not been published
or tagged automatically.

Do not enable GitHub Pages expecting it to run Python. This repository is a
free downloadable local app. Its artwork remains under separate terms.
