# Changelog

## 2.0.0

Added saved teams, drag-and-drop and accessible slot swapping, custom overlay
styling, nicknames/levels, fainted status and Nuzlocke stats, a shiny-hunt target
and encounter counter with focused-controller hotkeys, validated team/backup
import and export, repository artist credits, and Windows executable build tools.

Existing shiny support, manual entry, catalog search, automatic port selection,
local live sync, and old save compatibility are retained.
